Користувачі

Контакти менеджера підставляються у КП автоматично. Редагувати їх може тільки адмін.

Профілі

ПоштаПІБПосадаФіліяТелефонE-mail у КПРоль

Як додати нового менеджера

  1. Supabase → Authentication → Users → Add user → Create new user. Вкажіть пошту й пароль, увімкніть «Auto Confirm User».
  2. Профіль створиться автоматично. Якщо пошту заздалегідь внесено в таблицю pending_profiles (Supabase → Table Editor) — ПІБ, телефон, філія і роль підтягнуться самі; інакше — заповніть тут і натисніть «Зберегти зміни».
  3. Звільнення: не видаляйте користувача, у якого є сформовані КП (історія посилається на нього) — натисніть у Supabase Ban user. Видалення можливе лише для тих, хто ще нічого не формував.
Кнопка «створити користувача» прямо на сайті потребує серверної функції з сервісним ключем — заплановано на наступну версію.
